# OBS 設定テンプレート

`lib/70-obs.sh` が `~/Library/Application Support/obs-studio/` へ配置する設定テンプレートの置き場。

**現在テンプレートは未格納。** 格納されるまで、70-obs.sh は OBS 本体のインストールのみ行い、
設定配置は警告を出してスキップする。

## 採取手順（人間作業）

テンプレートはコードで生成せず、**検証済み実機からエクスポートしたものを格納する**。
OBS の設定ファイルはキー名・構造がバージョンにより変化するため、内容を推測して記述すると
「起動はするが設定が反映されない」という発見しづらい不具合を生む。

1. 検証用 Mac に OBS をインストールする（`brew install --cask obs`）
2. 手作業で理想の設定を完成させる（下表）
3. OBS を**完全に終了**する（終了時に設定がファイルへ書き出されるため、起動中のコピーは不可）
4. `~/Library/Application Support/obs-studio/` を丸ごとこのディレクトリの `obs-studio/` へコピーする
5. 端末固有情報・ログ・キャッシュを削除する（後述）

### テンプレートに含める設定内容

| 分類 | 設定項目 | 値 |
|---|---|---|
| シーン | シーン名 | `セミナー録画` |
| ソース | macOS 画面キャプチャ | 方式：ディスプレイ／「音声をキャプチャ」有効 |
| ソース | 音声入力キャプチャ | 既定のマイク（初期状態はミュート） |
| 出力 | 出力モード | 詳細 |
| 出力 | 録画フォーマット | `mkv` |
| 出力 | エンコーダ | Apple VT H264 ハードウェアエンコーダ |
| 出力 | 音声トラック | トラック1（画面キャプチャ音声）／トラック2（マイク） |
| 映像 | 出力解像度 | 1920×1080 |
| 映像 | FPS | 30 |
| 一般 | 初回起動ウィザード | スキップ |

> 「macOS 画面キャプチャ」の方式は、キッティングで全社配布する以上、確実性を優先し
> `ディスプレイ`（画面全体）を採用する。`アプリケーション`（Zoomのみ）は通知の映り込みが
> ない利点があるが、Zoom のウィンドウ状態により黒画面になる既知の不安定さがある。

### 格納前に必ず削除するもの（公開リポジトリのため）

- `logs/`、`crashes/`、`profiler_data/`
- `plugin_config/`
- 検証機固有のデバイス ID・ディスプレイ ID を含む値（可能な範囲で汎用値に置換、または初期値に戻す）
- 検証時に使用したファイルパス・ユーザー名を含む記述

### 期待されるディレクトリ構成

```
assets/obs/obs-studio/
├── global.ini                        # 使用プロファイル・シーンコレクション指定、初回ウィザードスキップ
└── basic/
    ├── profiles/
    │   └── EXG-Seminar/
    │       └── basic.ini             # 出力・映像設定
    └── scenes/
        └── EXG-Seminar.json          # シーン・ソース構成
```

（ディレクトリ名・ファイル名は OBS が実際にエクスポートしたものをそのまま使う）
