# OBS Studio 権限設定手順

キッティング（`lib/70-obs.sh`）で OBS Studio のインストールと録画設定の配置は自動化済み。
ただし**画面収録・マイクの権限付与だけは macOS の仕様上、ユーザー自身の操作が必要**。
このドキュメントはその手順と、なぜ自動化できないかの説明。

## ユーザーがやること（2ステップ）

1. **システム設定 > プライバシーとセキュリティ > 画面収録とシステムオーディオ録音**
   - リストから「OBS」を見つけてトグルをオン
2. **システム設定 > プライバシーとセキュリティ > マイク**
   - 「OBS」をオン（自分の発言も録音する場合のみ）

許可後、**OBS を再起動**すると反映される。

> OBS 初回起動時に権限を求めるダイアログが出た場合は、そこから「システム設定を開く」でも同じ画面に行ける。

## 録画のはじめかた

1. OBS を起動（シーン「セミナー録画」が設定済みで表示される）
2. 自分の発言も録音する場合は「音声入力キャプチャ」のミュートを解除
3. 「録画開始」を押す
4. 終了したら「録画停止」。ファイルは mkv 形式でムービーフォルダに保存される

録画は相手側音声（トラック1）とマイク（トラック2）が別トラックで記録されるため、
編集時にマイク音声だけ除去できる。

## なぜ権限付与を自動化できないのか

- TCC（画面収録・マイク等のプライバシー権限）データベースは SIP（System Integrity Protection）で
  保護されており、スクリプトから書き込めない。`tccutil` にも `reset` サブコマンドしかない。
- MDM の PPPC プロファイルでも、画面収録・マイク・カメラは「拒否」のみ設定可能で
  「許可」は設定できない。Apple の意図的な設計であり、抜け道は存在しない。
- したがって `TCC.db` への直接書き込み・SIP 無効化・サードパーティ製回避ツールは
  **いずれも使用禁止**（本リポジトリへの実装も禁止）。

## 運用メモ: PPPC プロファイル（Jamf Now 側の作業・本リポジトリ対象外）

貸与先ユーザーに管理者権限を付与していない運用の場合、標準ユーザーは画面収録の
トグルをオンにする際に管理者パスワードを求められ、必ず情シス依頼が発生する。

Jamf Now でカスタム構成プロファイルを配布できる場合、`ScreenCapture` に対し
`AllowStandardUserToSetSystemService` を有効化すると、標準ユーザーが管理者パスワード
なしで自分で許可できるようになる。

- プロファイルは iMazing Profile Editor 等で作成可能
- **カスタムプロファイルは Jamf Now の Plus プランでのみ利用可能**（Fundamentals プランでは不可）。
  自社の契約プランを確認し、Fundamentals の場合はプランアップグレードの要否を判断する
  - 参考: [Custom Profiles in Jamf Now](https://support.jamf.com/en/articles/11030452-custom-profiles-in-jamf-now) /
    [How To Create and Upload a Custom Profile to Jamf Now (iMazing)](https://imazing.com/guides/how-to-upload-configuration-profile-jamf-now)
- PPPC の `AllowStandardUserToSetSystemService` は `ScreenCapture` と `ListenEvent` の
  2サービスに対してのみ設定可能（macOS の仕様）

## トラブルシューティング

| 症状 | 原因・対処 |
|---|---|
| 録画したが真っ黒 | 画面収録の権限が未許可。許可して OBS を再起動 |
| 相手の音声が入っていない | シーンの「macOS 画面キャプチャ」ソースで「音声をキャプチャ」が無効になっていないか確認 |
| 自分の声が入っていない | 「音声入力キャプチャ」がミュートのまま（初期状態はミュート）。ミキサーでミュート解除 |
| 権限を許可したのに反映されない | OBS を完全に終了（⌘Q）して再起動 |
| 設定が初期状態に戻っている | `~/Library/Application Support/obs-studio.bak.*` に退避された旧設定がないか確認 |
